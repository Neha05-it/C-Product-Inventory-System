# 📦 Product Inventory System

A beginner-friendly C programming project that demonstrates the use of **Structures** through a simple product inventory management system.

## 📌 About the Project

The Product Inventory System allows users to manage product records in an inventory.

Users can add, display, search, update, and delete products. The program can also calculate the total inventory value and identify the most expensive product and the product with the lowest stock.

## ✨ Features

- ➕ Add Product
- 📋 Display Products
- 🔍 Search Product
- ✏️ Update Product
- 🗑️ Delete Product
- 💰 Calculate Total Inventory Value
- 📈 Find Most Expensive Product
- 📦 Find Lowest Stock Product
- 🚪 Exit
